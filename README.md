# dy下载器（Muse996）

在开源项目 DouK-Downloader（原 TikTokDownloader）基础上修改的定制版，只用于下载抖音内容。

## 已经删除

- TikTok（海外版）的全部下载功能
- 后台监听模式
- Web API 模式

## 保留的主要功能

- 终端交互模式：批量下载账号作品、链接作品、合集作品、收藏作品等（全是抖音）
- Web UI 模式：暂未开发完成，保留占位

## 自定义下载规则

- 图集达到设定张数（默认 2 张）：自动建一个文件夹，图片和背景音乐放在一起
- 实况照片：按图集处理，独立文件夹并带背景音乐
- 纯视频：直接放在下载根目录，不建文件夹、不下载背景音乐
- 文件名统一格式：日期-类型-作者-标题-作品ID-序号
- 文件夹命名可在主菜单「下载规则设置」里开关：日期、类型、标题、作品ID
- 已经下载过的作品，再次下载会自动跳过（包括背景音乐），也不会生成空文件夹

## 使用方法

1. 从本仓库的 Releases 下载最新打包的 Windows 程序，完整解压
2. 双击 DouK-Downloader.exe 运行
3. 按主菜单前两项把抖音 Cookie 填写好
4. 进入「终端交互模式」粘贴链接或账号即可下载
5. 下载规则可以在主菜单「下载规则设置」里调整
